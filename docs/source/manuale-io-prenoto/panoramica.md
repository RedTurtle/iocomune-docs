# Panoramica

**io-Prenoto** si basa sul CMS Plone versione 6. E’ lo strumento che consente ad un cittadino di prenotare appuntamenti presso gli sportelli virtuali dell’Ente, come previsto dalla normativa AgID.

[Si rimanda a questa sezione per i template grafici](https://italia.github.io/design-comuni-pagine-statiche/#appuntamento)

_DISCLAIMER: alcuni screenshot riportati in questo manuale potrebbero essere obsoleti o differenti per alcune_ _peculiarità, frutto di aggiornamenti successivi. Viceversa, le nuove funzionalità sono aggiornate._
