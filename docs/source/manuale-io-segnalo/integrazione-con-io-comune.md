# Integrazione con io-Comune

Un oggetto Segnalazioni è lo strumento direttamente integrato in io-Comune, il suo utilizzo lato admin/operatore presuppone una conoscenza base del normale funzionamento di io-Comune stesso. [Per qualsiasi dubbio consultare il manuale di riferimento.](https://docs.google.com/document/d/1BrlGYmE3Z4y6FMIrfBJWOX1P2JVEGzJZS6TRbeIiFSk/edit?tab=t.0)

Una segnalazione è un form online, suddiviso in step, attraverso il quale vengono sottomessi dati geolocalizzati e fotografie, che vengono poi elaborati dagli operatori comunali.
