# Attori coinvolti nel processo

I principali attori coinvolti nella costruzione, utilizzo e manutenzione delle pratiche sono:

- **Amministratore** : colui che crea il nuovo oggetto Segnalazioni e definisce le categorie con relativo setting
- **Cittadino** : colui che utilizza il form pubblico per segnalare un disservizio
- **Operatore** : utente o gruppo di utenti dell’Ente che lavora e gestisce le segnalazioni pervenute
