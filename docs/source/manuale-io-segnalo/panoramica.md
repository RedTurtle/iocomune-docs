# Panoramica

io-Segnalo si basa sul CMS Plone versione 6. È lo strumento che consente ad un cittadino di inviare segnalazioni di disservizio presso gli uffici competenti di un Comune (o altro Ente), come previsto dalle linee guida di Designers Italia.

_DISCLAIMER: alcuni screenshot riportati in questo manuale potrebbero essere obsoleti o differenti per alcune_ _peculiarità, frutto di aggiornamenti successivi. Viceversa, le nuove funzionalità sono aggiornate._
