# Panoramica

**io-Cittadino** si basa sul CMS Plone versione 6. E’ lo strumento che consente ad un cittadino di istruire presso un Comune una pratica digitale, attraverso diversi step, come previsto dalla normativa AgID.

[Si rimanda a questa sezione per i template grafici ed i flussi di servizio richiesti](https://italia.github.io/design-comuni-pagine-statiche/servizi/index.html)

NOTA: alcuni flussi particolari, ad esempio i [flussi di pagamento dovuti, potrebbero non essere ancora](https://italia.github.io/design-comuni-pagine-statiche/servizi/pagamenti-multa-scheda-servizio.html) del tutto implementati, o in via di realizzazione per alcune componenti (es. Integrazione con i sistemi di pagamento)
